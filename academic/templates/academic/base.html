Evaluación N°1: Desarrollo Backend con Django & DRF - Docente: Marcelo Alvarado
Arquitectura: Django 6 + DRF 3.18 + Vanilla JS Fetch
Acerca de la Evaluación N°1

Arquitectura de Enmascaramiento:

Las vistas HTML renderizadas (courses.html y students.html) sirven como cascarón visual. En segundo plano, JavaScript utiliza fetch() de forma asíncrona para consultar los endpoints de la API REST de Django REST Framework (DRF) y actualizar el DOM sin recargar la página.

Modelo Entidad-Relación implementado:

  • Teacher (id, first_name, last_name)
  • Course (id, name, teacher_id)
  • Student (id, first_name, last_name)
  • StudentCourse (student_id, course_id)
